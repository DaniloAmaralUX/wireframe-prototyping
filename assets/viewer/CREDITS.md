# Viewer incluído

Snapshot do Prototype Viewer adaptado pela Pitang a partir de [appariciojunior/prototype-viewer](https://github.com/appariciojunior/prototype-viewer), de Apparicio Bueno, base a017ed8. A licença MIT está em `LICENSE`. O seletor de versões reconhece a referência de Emil Kowalski.

A marca Pitang pertence aos seus titulares; a licença do código não transfere direitos sobre marcas. A fonte Inter é solicitada opcionalmente ao Google Fonts, com fallback do sistema, sem impedir uso offline.

Runtimes opcionais do UI SDK 0.1.0-beta.6 de [vercel-labs/ui](https://github.com/vercel-labs/ui), Apache-2.0. Licença em `template/vendor/ui-sdk/LICENSE`, também preservada nos bundles. Não é necessário instalar os pacotes npm para usar os runtimes incluídos.

Este diretório contém os arquivos necessários ao empacotamento da skill. Os hashes em `manifest.json` permitem identificar o snapshot distribuído. Não há dependência de checkout, serviços externos ou de outras skills em tempo de geração.
